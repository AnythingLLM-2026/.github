2. Run the Windows installer.
3. Install AnythingLLM for the current Windows user.
4. Launch the desktop application.
5. Select a local or connected AI model.
6. Create a workspace for your documents and projects.
7. Add files, configure your AI provider, and start working with your AI assistant.

AnythingLLM provides Windows builds for x64 and ARM64 systems. The official Windows documentation currently targets Windows 10+ and recommends installation for the current user rather than all users.

## Overview

**AnythingLLM download** provides a local-first AI workspace for Windows and PC users who want to chat with documents, run AI models, use RAG, build AI agents, and organize different AI workflows in separate workspaces. **AnythingLLM for Windows** combines document chat, local LLM support, AI agents, MCP compatibility, model configuration, file search, and automation features in a single desktop application.

AnythingLLM can work with local models as well as supported external AI providers. The desktop application also includes local model options, making it possible to build a private AI workflow directly on a Windows PC.

## RAG and Document Chat

AnythingLLM includes built-in RAG functionality for working with personal documents.

- Other supported document formats

The documents can then become context for conversations inside that workspace.
